# Раунд — сайт магазина техники с админкой

Концепт-редизайн сайта магазина электроники «Раунд» (Батайск, Аксай): лендинг с прайсом, отдельные страницы товаров и простая админ-панель, в которой владелец магазина сам меняет цены, наличие, фото и тексты — без программиста.

**Демо:** https://raund-tech.netlify.app

## Возможности

**Сайт**
- Прайс-лист на 50+ позиций с фильтрами по категориям, поиском и сортировкой по цене
- Страница товара: галерея, варианты памяти/цвета, старая цена, расчёт платежа в рассрочку, характеристики, похожие товары
- «Ценники на верёвочках» на первом экране с физикой покачивания, анимации появления при прокрутке
- Адаптивная вёрстка, уважение к `prefers-reduced-motion`
- Без фреймворков: чистый HTML, CSS и JavaScript, работает даже без сервера (данные по умолчанию встроены)

**Админка** (`/admin`)
- Вход по паролю (пароль хранится в переменной окружения, проверка на сервере с защитой от перебора)
- Быстрое редактирование цены и наличия прямо в списке
- Редактор товара: фото (загрузка с автоматическим сжатием в WebP), описание, характеристики, дублирование вариантов
- Управление главной страницей, контактами, бегущей строкой и блоком розыгрыша
- Резервная копия: экспорт и импорт всех данных в JSON
- Демо-режим при открытии с диска

## Стек

| Часть | Технологии |
|---|---|
| Фронтенд | HTML, CSS (custom properties, grid, `color-mix`), Vanilla JS |
| Бэкенд | Netlify Functions (Node.js, ES modules) |
| Хранилище | Netlify Blobs — данные сайта и загруженные фото |
| Деплой | Netlify, автодеплой из GitHub |

## Структура

```
├── index.html            главная страница и прайс
├── product.html          страница товара
├── admin/index.html      админ-панель
├── assets/
│   ├── site.css
│   ├── common.js         общие функции: загрузка данных, шапка, контакты
│   └── default-data.js   данные по умолчанию
└── netlify/
    ├── functions/        API: /api/data, /api/upload, /api/img/:key
    └── lib/auth.mjs
```

## Запуск

1. Форкнуть репозиторий и подключить его к Netlify (*Add new site → Import from Git*).
2. В *Site configuration → Environment variables* добавить `ADMIN_PASSWORD`.
3. Запустить деплой. Админка будет доступна по адресу `/admin`.

Локально сайт можно открыть просто как `index.html` — он покажет данные по умолчанию, а админка запустится в демо-режиме.
